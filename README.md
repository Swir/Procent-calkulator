## 🚀 About

**Percentage Calculator** is a lightweight Python desktop utility for quickly calculating a percentage of a base value and the remaining amount after subtracting that percentage.

It is useful for discounts, commissions, fees, deductions, budgeting and everyday percentage calculations without opening a spreadsheet or browser calculator.

It is designed for users searching for a **percentage calculator Python**, **discount calculator desktop app**, **Tkinter calculator**, **percentage of value calculator** or a small offline percentage utility.

---

## ✨ Features

| Feature | Description |
|---|---|
| 🔢 Base value | Enter any numeric starting value |
| % Percentage | Enter the percentage to calculate |
| 🧮 Percentage amount | Calculates the selected percentage |
| ➖ Remaining amount | Shows the value left after subtraction |
| ✅ Validation | Handles invalid input cleanly |
| 🪶 Lightweight | Simple Tkinter / ttk desktop app |

## 📦 Installation

```bash
git clone https://github.com/Swir/Procent-calkulator.git
cd Procent-calkulator
python Calculator.py
```

No third-party packages are required for a standard Python installation with Tkinter.
