## 🇵🇱 Polski

Procent Calculator to małe narzędzie desktopowe napisane w Pythonie. Program oblicza wskazany procent podanej wartości oraz pokazuje, ile pozostaje po jego odjęciu.

### ✨ Funkcje
- podanie wartości bazowej
- podanie procentu
- obliczenie wartości procentowej
- automatyczne wyliczenie pozostałej kwoty
- walidacja błędnych danych wejściowych
- prosty interfejs Tkinter/ttk

### 🚀 Uruchomienie

```bash
git clone https://github.com/Swir/Procent-calkulator.git
cd Procent-calkulator
python Calculator.py
```

## 🇬🇧 English

Procent Calculator is a small Python desktop utility for calculating a percentage of a given value and showing the remaining amount after subtracting that percentage.

### ✨ Features
- enter a base value
- enter a percentage
- calculate the percentage amount
- automatically calculate the remaining value
- invalid-input validation
- lightweight Tkinter/ttk interface

### 🚀 Run

```bash
git clone https://github.com/Swir/Procent-calkulator.git
cd Procent-calkulator
python Calculator.py
```
